# Simple Steps 0.1.1

On `simple-steps-core` 1.0.2 (`dbaf4c7`).

```bash
pip install "git+https://github.com/stusynakowski/Simple_Steps.git@v0.1.1"
```

## What reads differently on core 1.0.2

- **Every step's one output column takes the step's name**, sources,
  literals and the empty step included (in 0.1.0 those three still said
  `value`). A step with no output yet shows its 1×1 "empty" frame under the
  step's name.
- **Formula mistakes say how to write it.** Core took the app's asks (012):
  a resource passed by position binds as in Python
  (`summarize[mod.map()](wf["notes"], res["tiny"])`); an unquoted setting
  (`mod.sort(by=n)`) is refused with *"text needs quotes"* instead of failing
  later; a resource on its own, a step with no input and a source given one
  are refused; raw Python errors are gone from refusals; and 25 messages now
  say what was probably meant.

## New in the UI

- **The browser tab** shows Simple Steps' icon and name.
- **Reference boxes are labelled.** While a formula bar has focus, each box
  around the cells it reads carries a tab naming the reading step and the
  argument it fills: `dbl · n`, `dbl · input`.
- Dicts and text in a cell no longer carry a `{}` icon in front of their
  text; images, charts and tables keep theirs.

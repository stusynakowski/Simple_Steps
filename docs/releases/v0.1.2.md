# Simple Steps 0.1.2

On `simple-steps-core` 1.0.2 (`dbaf4c7`), as 0.1.1.

```bash
pip install "git+https://github.com/stusynakowski/Simple_Steps.git@v0.1.2"
```

## Core reads formulas

The app no longer has a formula parser of its own: core reads every formula
(`simple_steps_core.formula`), the same reader Python users of core have.
What that changes:

- **More forms work in the formula bar**: a condition picks rows
  (`wf["s"][cols["n"] > 1]`), a pick can be a tool's input
  (`dbl[mod.map()](wf["s"][0:2])`), and `select`, `slice` or `sort` can
  stand before a verb in one step. Reference boxes in the grid outline
  conditions too.
- **Mistakes are checked when you press Enter** (or change the step editor),
  against the workflow: whether the tool exists, one shape verb per step, a
  setting's type, which steps it may read. While you type, only whether core
  can read the text. The step's problems show in its summary, on its status
  pill and in the step editor.
- **Messages are core's**, and say how to write it.
- One mistake in a step no longer stops the others: a step core refuses
  carries the reason, and the rest of the workflow still syncs and runs.
- A step that uses a pick as a tool's input is edited in the formula bar; the
  step editor shows it as written text.

## Smaller

- The browser icon ships as `favicon.ico` too, and the icon links carry a
  version so a cached icon is replaced. A browser that showed Vite's logo for
  your app before 0.1.1 may still need its history cleared once.

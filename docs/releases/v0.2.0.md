# Simple Steps 0.2.0

The first release on PyPI. On `simple-steps-core` 1.0.2 (`dbaf4c7`), also
on PyPI from today.

```bash
pip install simple-steps
```

## Install from PyPI

- `pip install simple-steps` installs the app and `simple-steps-core`; `pip
  install --upgrade simple-steps` updates both. No more `--force-reinstall`.
- Each release pins the exact core it was built with
  (`simple-steps-core==1.0.2`). The commit that core release was built from is
  recorded in `pyproject.toml` (`[tool.simple-steps] core-commit`), and
  `scripts/preflight.py` checks that the submodule matches it.
- Installing from GitHub still works, for unreleased code.

## The copilot plans and builds with you

The chat pane is now a copilot with **one session per workflow**, saved in
the workspace (spec 018):

1. **Plan.** Describe the goal. It asks a few questions if it has to, then
   proposes a plan: the resources, the steps, and a dev plan of small
   **milestones**, each with a check on its output. The plan is checked
   before you see it. Accept it, or ask for changes.
2. **Build, one milestone per Continue.** It proposes the milestone's steps;
   you apply and run them; the next Continue checks the output against the
   milestone, then moves on or proposes a fix.
3. **Context and trace.** Notes and earlier workflows (as templates) are
   things it reads every turn; the Trace tab lists every turn: what it did,
   the model calls, how much context it read, what its checks found.

Any model works: an OpenAI-compatible server, Anthropic, or a Python function,
`Agent(generate=fn)`. Try a whole session without a model:
`python examples/agent_demo/copilot.py`. The pane's look is plain for now.

## Also since 0.1.3

- **Resources get a column** of their own at the start of the step layout,
  before step 1 (spec 017).
- A step's data can be **any size**: the grid shows it in pages of 200 rows.
- The step header's controls sit in its bottom corners; step run status shows
  on the header and the map; step colour palettes.
- The Formula panel labels each part of `f(x) = …` and stacks its fields.
